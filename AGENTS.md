# Unrestricted application publishers

This repository owns maintained test applications and licensed upstream mirrors.
Publish only to the untrusted GitHub Pages site, never the manager or runtime
origins. Application code here may deliberately attempt disclosure.

Keep application and build source readable TypeScript. Preserve upstream license,
copyright and source notices. Pin downloaded archives by SHA256 and retain their
source provenance. Record every publisher path modification. Do not add a backend,
proxy, runtime security exceptions or app-specific host behavior.

Keep scripts formatted with the checked-in Prettier settings. Run type checking,
format checks and the relevant standalone application controls before publishing.
